# Breadboard Power Supply Module (Custom PCB)
This project features a custom-designed **Breadboard Power Supply PCB**, developed using **KiCad**. The module is designed to plug directly into a standard breadboard and deliver clean, regulated **3.3V and 5V** outputs, making prototyping and testing embedded circuits easier and more reliable.

## Features

- Dual output voltage support: **3.3V** and **5V**
- Designed to fit directly into a breadboard
- On-board voltage regulator (AMS1117 or LM317)
- Power LED indicators for both outputs
- USB and DC barrel jack input options
- Output headers for easy external use
- Compact and efficient layout

## Technical Specifications

| Feature             | Description                         |
|---------------------|-------------------------------------|
| Input Voltage       | 6V–12V (DC jack or USB)             |
| Output Voltage      | Selectable 3.3V and 5V              |
| Regulator Used      | AMS1117-3.3 / AMS1117-5.0           |
| Max Current Output  | ~800 mA (depends on regulator)      |
| Dimensions          | Breadboard-compatible footprint     |

## Tools Used

- **KiCad 7** – for schematic and PCB design
- **EasyEDA / JLCPCB** – for fabrication (optional)
- Soldering station and basic electronics lab tools
