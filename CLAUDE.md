# Project instructions

- Inspect the repository before editing. `PCB_01.kicad_sch`, `PCB_01.kicad_pcb`, `PCB_01.kicad_pro` are the source of truth; do not modify them without an evidence-based, owner-approved reason.
- Never invent part numbers, ratings, voltages, currents, test results or fabrication status. Mark unknowns as unverified.
- Do not alter the circuit or layout to make documentation look better; record problems as recommendations (see `docs/circuit-design.md`).
- Keep real evidence (screenshots, ERC/DRC output, measurements); never imply a board was built or tested without it.
- Verify every relative link and image path after editing docs. Keep the BOM (`docs/bill-of-materials.csv`) consistent with the schematic.
- Do not commit, push or add a licence without explicit owner permission.
- Project uses KiCad 8.0 file formats.
